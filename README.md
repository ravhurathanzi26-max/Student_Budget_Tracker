Student Budget Tracker

Live Demo: https://ravhuratportfolio.infinityfreeapp.com/ (best viewed in Microsoft Edge)

A final-year Business Information Systems project that helps students track spending, manage budgets, and view financial summaries through an interactive web application. Built with PHP, HTML, CSS, JavaScript, and MySQL, developed in Visual Studio Code, and connected to a MySQL database via phpMyAdmin running on the XAMPP local server environment.

The project was inspired by my own need to manage spending more carefully — spreadsheets weren't motivating me to actually track anything consistently, so I built a system that would.
