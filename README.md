# Student_Budget_Tracker
Live Demo: https://ravhuratportfolio.infinityfreeapp.com/
Test it via Microsoft edge only, it is a free tier website host, via chrome google recognizes it as unsafe but if you first put the chrome on new incognito tab everything will be sorted.
Final-year Business Information Systems project that uses PHP, HTML, CSS, MySQL and a little bit of JavaScript to help students track spending, manage budgets, and view financial summaries. The system was developed using Visual Studio Code and connected to a MySQL database via phpMyAdmin running on the XAMPP local server environment.
The main purpose is to help students manage their finances using a system to replace spreadsheets that are not motivational to be used. 
It is better for me to track my spending via an interactive web application.
